# Probe Station

## Current Projects

### Initial Probe Station Setup (Summer 2026 - Now)
PI: [Oliver S. Lee](mailto:xli3086@gatech.edu)

A probe station is the essential post-fabrication tool that lands needle probes on a chip's contact pads to measure its eletrical characteristics, yet commercial systems cost roughly $10K-$100K, which is well beyond the budget of a student organization. This project will build a low-cost, DIY probe station capable of basic device characterization on chips we fabricate.
