### Wafer Scribing + Cleaving System (Summer 2026 - Now)
PI: [Anish Jindal](mailto:ajindal@gatech.edu)

Both final packaging and efficient processing in smaller-scale machines require that a wafer be cleaved into smaller constituent dies. In industry, this is typically accomplished by saws or lasers. This project aims to implement a budget-friendly yet effective solution to scribing wafers and breaking it into smaller dies for later processing.
