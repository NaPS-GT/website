# Introduction to FabuBlox
[FabuBlox](fabublox.com){ target="blank" } is a web application that functions as an unified collaboration platform for process designs; think Google Drive but for nanofabrication. If you would like to learn more, feel free to checkout this [video](https://youtu.be/f-0DshlcXM0?si=QKQB7bWRTn55GbDG){ target="_blank } on a presentation of FabuBlox by Dr. Jan Tiepelt, co-founder and CEO of Fabublox.
